The product's voice, inline. Use it wherever Shipmate knows something the developer doesn't.

```jsx
<TipBox title="Shipmate pre-answered 36 questions for you" />
<TipBox title="Shipmate tip">Apple rejects screenshots with device frames. We stripped them for you — review before submitting.</TipBox>
<TipBox icon="!" wash={false} title="Heads up">Adding Brazil means a local ClassInd rating alongside IARC.</TipBox>
```

Purple, always. If the message is "you have not answered this yet" it is not a tip — use the orange required treatment on the field itself. If it is "this will get you rejected", use `AlertBox`.
