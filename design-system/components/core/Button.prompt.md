Pill action button — use for every modal footer, form submit and inline confirm in the Shipmate app.

```jsx
<Button variant="primary">Launch Dashboard →</Button>
<Button variant="ghost" size="sm">Cancel</Button>
<Button variant="danger">Delete anyway</Button>
```

Variants: `primary` (white fill, dark ink), `ghost` (panel-3 fill, dim text), `danger` (magenta). Sizes `md` / `sm`. Never tint a Button green — use `CtaButton` or the submit-step affordance for shipping actions.
